# 技术架构

> 「替爸妈点一下」——AI 手机管家。本文件描述系统组成与关键技术路径。

## 总体链路

自然语言请求 → 任务理解与规划 → 屏幕观察 → 物理执行 → 结果验证 → 反馈

## 组成

### 设备端(OnDeskBot)

- **主控**:ESP32-S3,负责设备侧控制,以及与服务端的通信
- **视觉**:摄像头,采集手机屏幕画面
- **执行**:机械臂驱动,在真实手机屏幕上完成点击、滑动
- **通信**:MQTT / HTTP,与服务端交换任务与状态

### 服务端(Agent)

- **任务规划**:把自然语言需求拆解为可执行的步骤序列
- **屏幕理解**:视觉语言模型(VLM)理解当前屏幕,判断状态与下一步
- **执行反馈**:下发设备指令,读取执行结果,验证是否达成目标,必要时重规划

## 关键设计

- **观察—决策—执行—验证闭环**:不是固定脚本,Agent 根据当前屏幕决定下一步动作
- **授权与确认**:高风险操作(支付、购买、删除、账号安全)在执行前暂停,交由本人确认
- **失败可恢复**:单步失败时重试或回退,而不是盲目继续
