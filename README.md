# OnDeskBot · 替爸妈点一下

**AI 手机管家**——让 AI 替爸妈操作手机,解决远程教不会的难题。

> 京东 Aidol 创造营 S2 · **AI 设备联动**赛道参赛作品

---

## 为什么做这个

父母面对越来越复杂的手机:菜单会变、广告会弹、常用功能找不到。异地子女只能隔着视频一遍遍教——"你点右下角""不是这个,再返回去"——而父母眼中的界面和孩子描述的界面根本不一样。一个几分钟能解决的问题,常常要折腾半小时。

问题不在于父母不会学,而在于我们把越来越复杂的手机,交给了越来越难跟上变化的人;而我们又没办法每次都在他们身边。

**OnDeskBot 是这个产品的一双手**:它看得见手机屏幕,也能像人一样点击、滑动,在父母授权后替他们把事情做好。

## 怎么工作

```
父母用自然语言说出需求
        │
   服务端 Agent
   理解意图 → 规划步骤 → 观察屏幕 → 检查结果
        │
   手机界面(系统设置 / 微信 / 支付宝 / 购物 App)
        │
   OnDeskBot 设备
   摄像头观察屏幕 + 机械臂执行真实点击、滑动 → 验证结果 → 反馈
```

用户说一句话,AI 负责理解、观察、规划,设备负责在真实手机上把动作执行出来,执行完再回头验证结果。

## 三个场景

| 场景 | 说明 |
|---|---|
| **手机没声音了** | 排查静音、音量等常见设置问题,让手机恢复响铃 |
| **广告少一点** | 开启微信 / 支付宝长辈模式,关闭可关闭的推荐与营销入口 |
| **帮我找一下上次买的那种东西** | 打开 App、找到商品、识别信息;下单 / 付款前必须由本人确认 |

三个场景对应:解决问题 → 减少困扰 → 完成生活事务。

## 边界

产品涉及父母的个人手机,**信任是产品的一部分**:

- **操作前授权**——用户明确选择要解决的问题并确认允许的操作,设备不在未经同意时翻看消息、照片或账户信息
- **高风险暂停**——支付、转账、购买、删除数据、修改账号安全设置等必须由本人确认
- **不夸大**——不宣称"长辈模式"能屏蔽所有广告、诈骗或误操作,只识别实际可用的设置并验证是否生效

## 组成

- **设备端**:ESP32-S3 主控 + 摄像头 + 机械臂驱动,负责真实手机屏幕的物理交互
- **服务端**:Agent 负责任务规划、屏幕视觉理解与执行反馈
